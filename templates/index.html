{{ icon('info') }} Important model limitation

The model has comparatively weaker detection performance for R2L and U2R attack categories. Predictions should be treated as decision-support information rather than guaranteed detection.

In this project's test evaluation, Random Forest detected fewer R2L and U2R attacks than Logistic Regression, so check the selected algorithm shown with every result.

Risk levels: Normal = Low, PROBE = Medium, DOS and R2L = High, U2R = Critical. These are application-defined, not part of the dataset.
